# 实施与验收

| 里程碑 | 实施任务 | 验收标准 | 当前状态 |
|---|---|---|---|
| M1 | 登录、资料库、Adapter、JSON导入、原始保存、去重、快照、迁移、Compose | 登录→导入模拟包→看到1视频2评论；重复导入无增加；失败可重试；缺失指标为null | 已实现，容器运行待验 |
| M2 | 采集器字段映射、CSV映射、出站Agent、RQ、聚类、需求证据、搜索分析、选题双级评分、保留期限 | 使用真实授权导出；每结论可追溯；重复评论不重复计权；卡片批准/合并/拒绝持久化 | 待开发 |
| M3 | Provider配置、预算/用量、持久讨论、创作决策、文案版本、局部修改/锁定/差异/撤销、事实审核 | 两种Provider可切换；重启恢复；锁定块不变；并发编辑冲突可见；无来源事实标记待核 | 待开发 |
| M4 | 分镜编辑、MD/JSON/SRT导出、手机验收、云部署、日志/备份演练 | 选题→讨论→逐字稿→局部版本→分镜导出全链；恢复备份后内容一致；实际iPhone与HTTPS通过 | 待开发 |
| M5 | 制作/配音适配、发布效果导入、计划采集、评分校准 | 真实数据、相关性标记、费用透明、无单样本因果结论 | 可选 |

每阶段提交独立代码、执行最贴近核心流程的测试并记录实际结果。前一阶段验收不意味着后续功能已完成。先以小批真实数据验证证据链，再扩展批量与自动化。
