# 架构与边界

## 当前交付：M1 基础工程

浏览器（PC/iPhone）→ Caddy 单一域名与 HTTPS → Next.js 界面及 FastAPI API → PostgreSQL。
开发时可用 SQLite，无 Docker 也可验证导入链路。生产数据库为 PostgreSQL，Alembic 负责迁移。

本仓库没有现有采集器；standard-json 是已实现的输入适配器，samples 中仅有明确标记的模拟数据。未接入抖音，也未调用任何模型。M1 不包括需求识别、选题或文案生成。

原始 JSON 保存在 import_jobs.raw_data；标准化视频、评论与每次采集的指标快照分别入表。业务列表始终返回 is_demo。未知指标用 null，不填 0。发布时间可缺失；来源 URL、带时区采集时间、平台和外部 ID 必填。当前输入上限 5MB / 200 视频，每视频 5000 评论；大批量需切分提交。

视频唯一键为平台＋外部 ID＋模拟标记；评论唯一键为视频＋外部评论 ID。内容完全相同的请求通过 SHA-256 幂等复用任务；新增采集时间建立新指标快照。原始记录保留任务元数据，失败时回滚标准化事务，并保留失败状态和重试入口。补采省略可选字段时保留旧值，显式null或空数组可以清除；已有评论更新文本和显式提供的点赞数。采集时间归一到UTC，迟到的历史包保留快照，但不覆盖较新视频及已有评论。

M1 小批量导入同步执行，数据库事务保证原子性；PostgreSQL 行锁避免同一任务同时重试。进程中断留下 pending 任务，可通过 retry 恢复。SQLite 仅用于单进程开发，不承诺并发导入。长时间 AI 任务必须在 M2/M3 引入后台队列后上线。

## 资源与部署取舍

2 核 4GB 的目标环境先只运行 Caddy、Next Node、单进程 FastAPI、PostgreSQL。当前不加载本地大模型、不做视频渲染、不存视频文件，不引入暂时无用途的 Redis 和 MinIO 常驻容器。部署时现场测 RSS、磁盘与延迟；此处不宣称做过服务器容量压测。前端在本机或 CI 构建镜像，避免小服务器构建时内存尖峰。

M2 引入 Redis+RQ 单 worker，避免 AI 请求占用 Web 进程。对象存储使用云 S3 兼容服务保存媒体和导出，不在 4GB 主机运行 MinIO。采集器若依赖 Windows，通过本地 Agent 主动出站 HTTPS 推送标准包；不开放浏览器调试端口，不向云上传 Cookie。当前仅完成协议边界，本地 Agent 尚未实现。

## 后续模型与创作设计（未实现）

Provider 配置与业务分离：provider、base_url、model、能力、超时、重试参数、推理参数、输入/输出单价、生效日期、服务端 secret_ref。适配器统一 research/generate/structured_output 接口，网络错误指数退避，非幂等生成发生超时应标记 outcome_unknown，不盲重试扣费。

AI job 持久化输入 hash、项目、阶段、provider 配置快照、状态、进度、心跳、幂等键、用量及费用。执行前预留预算；结束按实际 usage 结算。供应商无 usage 时标为估算。数据库 outbox 投递队列，任务租约与 fencing token 防并发写回；结果提交后再确认任务。任务进程重启须能恢复。

内容源被视为不可信数据；评论或网页内指令不能触发工具执行。结论保存 evidence 引用（来源 URL/评论 ID/采集时间）、覆盖范围、支持程度、不确定性。语义聚类与启发式评分显示依据及权重，不声称预测播放量。

project 保存阶段、受众、叙事方向；decision 追加记录批准/拒绝/替换及理由；script_version 不可变；script_block 具有稳定 ID、锁定状态；重写以 base_version 乐观锁写入，禁止修改锁定块。主编导按需调用研究/事实核查/视觉规划，设置轮数与成本上限。分镜引用具体文案版本和段落 ID，避免修改文案后静默失配。

## 安全、隐私与限制

单用户环境变量密码，HMAC 签名 HttpOnly/SameSite=Strict 会话，生产必须 Secure Cookie + HTTPS。密码与会话密钥只在服务端。登录限流当前为单进程内存窗口，重启清空；公网正式上线前建议再加入口限流。退出仅删除当前 Cookie；需要全局撤销时轮换 SESSION_SECRET。没有默认公开分享。

原始导入包含评论，应按私有资料备份。当前提供按模拟/真实数据分别全量删除 API，删除同时移除原始任务和指标；尚无自动保留期限与按日期清理，M2 必须补齐可配置保留策略。备份也需按保留策略轮换，删除线上数据不会自动擦除历史备份。
