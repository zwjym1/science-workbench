# 第二轮完善与真实回归

2026-10-20，北京时间。本轮实际实现与测试，不宣称全部功能完美实现。

## 已实现

- 新增 public_api.py：从已验证的 so.douyin.com 官方公开接口取得详情、有限评论分页与回复；CLI/MCP 显式 source=public。没有被拒后自动切源。
- 新增 search.py：补读正常搜索页面的内嵌数据，修复只监听网络响应导致已有视频漏采的问题；提取出的脚本仅作为 JSON 数据解析，不执行。仅覆盖初始页观察到的候选，按真实 create_time 筛时间，按候选点赞排序。
- 搜索作为持久任务，新增 submit_search MCP 工具和 search 命令，沿用缓存、原始证据、worker、来源暂停。视频结果支持 offset/limit。
- 限量截断明确 partial；回复采样明确 partial；多父评论 total 按父评论记录，汇总仅覆盖选中的父评论。整体任务状态纳入详情、评论、回复及显式请求的媒体/转写/OCR。
- 保留下载权限与公开地址检查，不接入第三方解析站，不在明确拒绝后换源。
- 审查发现的搜索限制被清理异常吞掉、搜索 offset 无效、回复总数覆盖问题已修复并补回归测试。

## 20 条新来源实测

沿用此前同一组固定样本 ID，使用新建独立游客目录、逐条执行 public 来源；每视频最多 2 个一级评论页、40 条一级评论，回复只有限采样。不是新一组随机样本，也不是最近三天热门榜。

| 项目 | 结果 |
|---|---|
| 详情 | 20/20 |
| 一级评论 | 387 条，逐视频归属校验去重后相加 |
| 回复 | 130 条，包含内嵌与展开回复合并去重，不等同全部回复 |
| comment_top_rec 非空 | 14/20 |
| feed_bottom_rec 非空 | 14/20 |
| 任务状态 | succeeded 4、partial 16、paused 0、failed 0 |
| 原始证据 | 90 份响应 SHA-256 重新验证全部通过 |
| 人工登录/验证码 | 无；未导入个人账号 Cookie |

数据：data/public20-live/summary.json、results.json；数据库及原始响应保留本地。相比旧浏览器批次 129 条一级评论、50 条合并回复，新来源取得更多数据；两个批次采集时间、采样预算与返回排序不同，不能把差额解释为固定提升比例。旧批次“27 回复”是仅展开口径，不能与 130 合并回复直接比较。

本轮执行过程中补了防御性代码与测试，因此批次不是冻结版本基准。最终修复后只重复自动测试，未重新请求全部 20 条。

## 搜索与媒体回归

统一入口搜索“科普”：实际发现 2 条视频，包括“随手拔的一根草怎样吹出像哨子一样的响声”（点点科普）与“为什么没有3条腿或者5条腿的动物呢？”（念念的频道）。均有真实 ID、create_time、互动数据，结果明确 partial、ranking_scope=observed_candidate_pool_only。不能声称全站最热。

统一入口两条已知视频：合计 11 条一级评论、11 条合并回复；其中一条取得 comment_top_rec、feed_bottom_rec、detail_inbox_rex 等不同场景字段；两条均缺原字幕。

对允许下载的 7667409251216819441 实际尝试媒体流程，但官方域名 v26-dymsearch.douyinvod.com、v3-dymsearch.douyinvod.com 在本机解析为非公网地址，安全预检返回 unsafe_url，尚未发出媒体请求。未关闭安全检查，也未更换解析站。因此本轮没有取得新媒体或新 ASR 文本。此前其他环境/上下文成功下载的证据仍存在，不能混写成本轮成功。

## 仍未完美或未验收

- 不保证全量评论/回复、任意视频下载、每条都有推荐词或原字幕。
- feed_bottom_rec 是真实字段来源，14/20 只说明本批覆盖，未证明跨日稳定或所有客户端界面一致。
- 搜索仅初始候选页，搜索框联想接口在独立 skill 测试可用，尚未接入统一 MCP 单独功能；关键词级推荐词与逐视频搜索字段分开。
- OCR、短链解析仍待实现；完整口播的本地 ASR 样本验收待补。
- PostgreSQL 实例、远程 HTTPS/认证、常驻 worker 部署和真实 Gemini 客户端尚未验收；当前 MCP 仍为本地 stdio，电脑关机后不会继续运行。
- 本机媒体 DNS 问题需要在正常公网解析环境复核；不能通过放开内网地址作为解决办法。
