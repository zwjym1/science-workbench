# ChronoAtlas 项目需求存档

用户要求：创建中国古代史 AI 地图纪录片自动化系统。输入历史选题，AI 自动规划解说与分镜，使用真实地理数据绘制地图、疆域、行军路线和战役动画，输出纪录片视频。

技术：React + TypeScript 可视化控制台；SVG + D3-geo 地图；Remotion 动画与视频渲染；SQLite + GeoJSON 历史地理数据库；Node.js 后端与任务；AI 历史研究、分镜和动画指令。

视觉：古典羊皮纸、山川河流、历史城池、朱红行军箭头、疆域变化、时间轴、电影感镜头。首个测试《为什么河西走廊如此重要？》。

执行要求：先检查 Windows；建立完整工程与 AGENTS.md；优先实际运行地图引擎；地图数据经过核验，不编造历史位置；记录历史素材来源及商业许可；第一阶段必须输出真实可播放30秒 MP4；逐步开发网页编辑器、AI编导、数据库、音视频合成。优先画面效果、可编辑性、稳定性和扩展能力。
