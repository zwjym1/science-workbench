**技术方案：**

- React + TypeScript：可视化控制台

- SQLite + GeoJSON：历史地理数据库
- Node.js：后端和任务管理
- AI：历史研究、分镜生成、动画指令生成

古典羊皮纸、山川河流、历史城池、朱红色行军箭头、疆域变化、时间轴和电影感镜头。
