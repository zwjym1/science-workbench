# ChronoAtlas 开发约定

目标：中国古代史 AI 地图纪录片自动化系统。首个选题《为什么河西走廊如此重要？》。

## 架构
- src：React/TypeScript 编辑器、SVG + D3-geo 地图、Remotion 确定性动画；同一组件用于网页预览和视频输出。
- data：可追溯 GeoJSON 与地点；docs/sources.json 记录许可、来源、SHA256。
- server：Node.js 原生 HTTP + SQLite，项目与任务持久化。只监听本机。
- scripts：素材核验、数据库初始化、渲染检查；out：真实交付物。

## 规范
- 动画只由 Remotion frame 驱动，不使用随机数、网络请求或 CSS animation。
- 经纬度采用 WGS84 [longitude, latitude]。不得凭空补全古城址、古河道、历史疆域或行军路线。
- 现代参考位置、示意路径、考证历史数据必须明确区分。无来源的数据不可进入正式历史图层。
- 素材必须具备来源、下载日期、许可、商业使用状态和内容摘要。未确认授权的图片、音乐不得打包。
- API 密钥仅存服务端环境变量；AI 输出需结构校验和人工史实审核，不能直接升格为史料。
- 尊重父工程既有修改。本项目范围仅限 ChronoAtlas/。

## 阶段与验收
1. 地图引擎：30秒、1280×720、30fps H.264 MP4，能完整解码；四镜头；地图来源可追溯；预览与导出共用代码。
2. 编辑器：可编辑标题、配色、分镜；保存/载入项目；调时间轴；渲染任务状态与失败日志。
3. 历史数据：来源/许可/时间有效区间/不确定性、别名、古今关系；史学审核通过才发布。
4. AI 编导：输入选题→检索→逐条事实表→分镜 JSON→审核→动画参数；保留模型与提示词版本。
5. 音视频：已授权配音音乐、字幕、混音、1080p/4K，任务恢复。

验证：npm run typecheck；npm run build；node scripts/catalog.mjs；node scripts/verify-video.mjs。变更动画后抽帧目视检查，不以代码编译代替视频验收。
